# Сервисы производства Кадриана

Проверено по документации поставщиков 17 ноября 2026. Наличие адаптера в коде и рабочего API-доступа на сервере проверяется отдельно.

| Формат | Подключение | Работа в этой версии |
| --- | --- | --- |
| Общение и режиссура | OpenAI GPT-6.1 Terra | Память проекта, сценарий, обсуждение изображений. Модель задаётся KADRIAN_CHAT_MODEL. |
| Живые сцены и мультфильмы | Runway Gen-4.5 | Существующий путь опорное изображение → движение → монтаж FFmpeg. |
| Короткая сцена со звуком, мультфильм | HeyGen Video 1 | API v3, 5–30 секунд, 1080p. Стиль задаётся сценарием. Сохранённый эскиз можно выбрать как первый кадр. |
| Один ведущий | HeyGen Avatar 6 / V / IV | Выбор публичного образа и русского голоса. Доступные модели проверяются по образу. |
| Интервью двух ведущих | HeyGen Studio | Чередование отдельных планов. Реплики и голоса согласуются до запуска. |
| Музыка | ElevenLabs | Существующий музыкальный инструмент студии. Готовые дорожки доступны для сборки Shotstack. |
| Облачная сборка | Shotstack Edit API | Последовательность сохранённых MP4 выбранного проекта и необязательная музыкальная дорожка. Длительность каждого фрагмента задаёт пользователь. |

API-ключи хранятся в защищённых настройках веб-сервиса и content-worker. Кадриан использует только KADRIAN_HEYGEN_API_KEY. HEYGEN_API_KEY и HEYGEN_KEY принадлежат прежним интеграциям и Кадрианом не используются. Для Shotstack используется SHOTSTACK_API_KEY. Подключение HeyGen в Codex подтверждено по профилю аккаунта, API-доступ сервера Агентства пока не проверен.

HeyGen и Shotstack запускаются через существующую фоновую очередь. Перед платным запросом сохраняется отметка о запуске. После ответа сохраняется идентификатор задачи. При неизвестном результате повторный платный запрос останавливается, при известном идентификаторе продолжается проверка результата. Готовый файл до 100 МБ сохраняется в хранилище владельца и попадает в библиотеку без автоматической публикации. Для более крупного файла сохраняется задача поставщика; кабинет получает свежую ссылку на результат для просмотра и скачивания. Такой файл нужно скачать для собственного архива.

Для оценки расходов задаются фактические тарифы аккаунтов из .env.example. Смета округляет длительность вверх до минуты. Для речи используется приблизительная оценка темпа, фактическая длительность и списание могут отличаться. API поставщика не принимает общий денежный предел в данном запросе. Доступные лимиты расходов настраиваются также у поставщика. Разговор с ИИ оплачивается отдельно.

Работа с частными аватарами и голосами клиентов требует настройки их проектного доступа. В этой версии каталог ограничен публичными образами и голосами HeyGen.
