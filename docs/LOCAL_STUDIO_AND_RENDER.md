# Студия «Контент» на Mac и на Render

- Рабочий кабинет Агентства W открывается на [Render](https://agency-w-web.onrender.com/). Streamlit используется как интерфейс.
- [Локальный кабинет](http://127.0.0.1:8765/) открывается на Mac, где запущен процесс. Он использует код существующей студии и отдельную SQLite, привязанную к этому Mac.

## Локальный запуск

Запустите из выбранной рабочей копии GitHub `tools/run_local_studio.sh`. По умолчанию команда использует Python из `../.local-studio/venv` рядом с репозиторием. Для нового окружения используйте Python 3.12 и установите `requirements.txt`. Окружение и данные можно указать через `KADRIAN_LOCAL_PYTHON` и `KADRIAN_LOCAL_DATA`. Рабочие файлы и базу `preview.sqlite3` храните вне временной папки и вне Git. Резервируйте вместе базу и каталог `preview-media`. Проверка запуска — `http://127.0.0.1:8765/_stcore/health`.

Монтаж использует `ffmpeg`, `ffprobe` и локальную модель Whisper для временных меток речи. Редактор сценария может использовать локальную модель llama.cpp. Замена фона через Apple Vision рассчитана на macOS.

## Перенос в существующий кабинет

1. Сверить коммит активного развёртывания Render с GitHub. Зафиксировать исходное поведение видео, календаря, материалов и прав доступа. Сверить переменные обратных ссылок для OAuth и оплаты с зарегистрированными callback URL. Ссылки на Streamlit Cloud в старых инструкциях и архивах считать историческими.
2. От отдельной ветки подготовить PR с обычным сохранением исходников, сценария, образа и версий. Добавить проверку изоляции владельцев, сохранения и восстановления черновика, оригинальной звуковой дорожки и отсутствия обращения к платным API. Использовать синтетические материалы в CI.
3. Проверить FFmpeg, шрифты, Whisper и лимиты памяти/времени в Linux. Для длительного монтажа использовать очередь и существующий worker после проверки его ресурсов и повторного запуска задач. Хранить результаты в существующем защищённом хранилище. Для замены фона на Linux нужен отдельный проверенный модуль сегментации или предварительно подготовленный клип с фоном.
4. После отдельного согласования включить возможность для одного тестового проекта на существующем сервисе. Проверить создание из готового клипа, просмотр, скачивание, повторный монтаж и соседние функции. Сохранить прежний коммит и возможность выключить функцию. После приёмки расширить доступ по отдельному согласованию.
