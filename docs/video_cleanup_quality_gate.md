# Агентство W — критерии возвращения «Очистить видео»

## Почему временно отключено
18.10.2026 проверка на двух загруженных роликах показала, что
схема FFmpeg `delogo` с постоянной прямоугольной маской портит лица,
фон и субтитры. Она не определяет, в какие секунды и где находится
движущийся знак TikTok. Оценка готового результата — неприемлемо
для публикации под брендом Агентства W.

Режим должен оставаться скрытым для всех партнёров, пока
не пройдено полное визуальное испытание. Сохранённый код
`content_video_cleanup.py` является прототипом, не готовой услугой.

## Контрольные видео (только локальные тесты, не добавлять в репозиторий)
- «Ничего не получается.mp4» (около 59 секунд)
- «WhatsApp Video 2026-10-18 at 08.36.15.mp4» (около 62 секунд)
- Неудачный результат «agency_w_video_cleaned (1).mp4» (для сравнения дефектов)
- Исторический пример удачной индивидуальной обработки:
  «Счастья_вам_желаю_без_TikTok.mp4». Точная команда прошлой
  обработки пока не восстановлена — не приписывать ей несуществующий API.

## Алгоритм следующего прототипа
1. Находить положение знака по времени, а не стирать две области постоянно.
2. Отдельно обнаруживать логотип и ник, сопоставлять соседние кадры.
3. При пересечении маски с глазами, ртом, лицом, важными титрами —
   не применять слепой `delogo`; помечать сцену как требующую проверки.
4. Предлагать обрезку финальной TikTok-заставки, не обрезая слова/музыку.
5. Не передавать пользовательские видео внешнему API без ясного согласия.
6. Не показывать сообщение «очищено» без проверки качества: максимум
   «обработано, проверьте результат».

## Приёмка: обязательна ПЕРЕД возвращением кнопки
- В обоих контрольных роликах знак/ник удалён, а не просто размыт.
- По всей длительности, особенно около 7, 12, 17, 37, 42, 47 секунды,
  нет заметных прямоугольников на лицах, глазах, ртах и субтитрах.
- Звук, речь, музыка и соотношение сторон сохранены.
- Нет заметных грубых искажений и случайного обрезания содержания.
- Выборочная проверка разных кадров и финала — визуально вручную,
  плюс автоматические тесты. Автотесты с цветными тест-полосами
  НЕ являются доказательством реального качества.
- Только после двух успешных MP4 разрешено включать кнопку
  `Очистить видео` в действующем `render_content_factory`.

Правило: качество до распространения партнёрам. Не включать
функцию на боевом экране «для проверки», если прототип не принят.
