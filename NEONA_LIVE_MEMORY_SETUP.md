# Неона — живая память диалога для Карточки человека 2.0

Версия: 1.0  
Дата: 23.08.2026

## Что добавляет комплект

После нового входящего сообщения Неона работает по прежней действующей политике: понимает ответ, отвечает, обрабатывает возражение и ведёт к осознанной встрече. Только ПОСЛЕ формирования ответа отдельный слой памяти сохраняет смысл хода разговора в уже существующий `agency_dialog_states.context`.

Карточка человека 2.0 начинает показывать:

- последний смысл ответа человека;
- то, что человек сам явно сообщил;
- прозвучавшие цели / задачи / потребности;
- реальные вопросы человека;
- явно выраженные предпочтения;
- возражения;
- последний ответ Неоны;
- краткую живую историю диалога;
- текущую границу общения и следующий допустимый шаг.

## Что принципиально НЕ меняется

- прежняя логика переговоров Неоны;
- работа с возражениями;
- переход к встрече;
- календарь;
- правило «не писать снова без нового входящего»;
- явный запрет «не пишите / не присылайте»;
- первые сообщения;
- Неония, Стагирит и Неола.

## Безопасность

Память не участвует в принятии решения и не редактирует ответ Неоны. Если извлечение смыслов не сработало, диалог всё равно продолжается. В этом случае сохраняется безопасная краткая запись без домыслов.

Подтверждёнными фактами считаются только сведения, которые человек сам явно сообщил. Аналитические предположения Неонии остаются отдельно и не смешиваются с фактами из разговора.

Новая SQL-таблица НЕ требуется: используется уже существующее JSON-поле `context` таблицы `agency_dialog_states`.

## Файлы

1. `neona_memory.py` — новый слой живой памяти.
2. `neona_dialog_policy.py` — прежняя политика Неоны + безопасный вызов памяти после ответа.
3. `person_card.py` — показывает накопленную память в Карточке человека 2.0.
4. `NEONA_LIVE_MEMORY_SETUP.md` — эта инструкция.

## Проверка после установки

1. Убедиться, что Агентство W открывается без ошибки.
2. Открыть `Агенты → Неона` — текущие карточки должны выглядеть как раньше.
3. Дождаться нового реального ответа одного из людей.
4. Проверить входящие обычным действующим способом.
5. Открыть Карточку человека 2.0: должен появиться блок `💬 Живая память Неоны`.
6. Убедиться, что сохранены только смыслы реального ответа, а не придуманные сведения.
