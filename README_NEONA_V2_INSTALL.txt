ПОСЛЕ DEPLOY — БЫСТРАЯ ПРОВЕРКА
-------------------------------
A. «Я занимаюсь бизнесом»
Ожидание: разговор идёт к времени, а не к консультации по продукту.

B. После вопроса Неоны о сокращении времени: «Да, конечно»
Ожидание: сразу 2–3 свободных варианта МСК.

C. «Сколько стоят ваши услуги?»
Ожидание: вопрос к Валентине + сразу свободные варианты МСК.

D. «Я не хочу разговаривать с ИИ, хочу с человеком»
Ожидание: это НЕ отказ; Неона сразу организует переход к Валентине.

E. «Нет, спасибо, мне неинтересно»
Ожидание: без возражений и дожима; открытая дверь и завершение.

F. Выбрать слот «2»
Ожидание: Неона спрашивает только формат:
Zoom / Telegram / WhatsApp.

G. Выбрать формат «Telegram»
Ожидание: встреча сразу создаётся в календаре,
без дополнительного «Подтверждаете?».

ВАЖНО
-----
- Все времена, которые Неона предлагает человеку, — по Москве (МСК).
- Часовой пояс человека Неона не спрашивает.
- Если 3 варианта не подходят, Неона ищет следующие.
- Неона сообщает «встреча записана» только после реального создания записи.
- Цена, технические вопросы, кейсы/результаты, просьба поговорить с человеком —
  мостики к Валентине.
- Неона не даёт медицинских и других посторонних консультаций.
