# Разведчик W v1.0 — установка

## Что входит

- `streamlit_app.py` — добавляет Разведчика в список агентов внутри Стагирита.
- `scout_center.py` — рабочий модуль веб-разведки.
- `SCOUT_CORE.md` — ядро роли.
- `SCOUT_REGLEMENT.md` — правила работы.
- `SCOUT_COMPETITOR_CARD.md` — стандарт карточки конкурента.
- `scout_reports.sql` — постоянная история отчётов в Supabase.
- `SCOUT_SETUP.md` — эта инструкция.

## Установка

1. Загрузить все файлы в корень GitHub-репозитория W.
2. Открыть Supabase → SQL Editor.
3. Выполнить `scout_reports.sql` один раз.
4. Дождаться перезапуска Streamlit.
5. Открыть `🤖 Агенты → Разведчик W`.
6. Ввести одного конкурента и нажать `🛰️ Провести разведку`.

Если SQL ещё не выполнен, сам отчёт всё равно может сформироваться, но постоянная история не сохранится.

## Безопасность v1.0

Разведчик работает только вручную по команде Директора. Он не публикует результаты, никому не пишет, не изменяет код W и не запускает фоновый мониторинг.
