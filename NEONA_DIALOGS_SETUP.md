# Неона: входящие Telegram-диалоги — этап 1

Этот комплект добавляет безопасную обработку входящих сообщений от людей, которым из Агентства W уже было отправлено утверждённое первое сообщение.

## Что уже делает модуль

- отвечает только людям из журнала реально отправленных первых сообщений;
- при первом запуске создаёт точку отсчёта и не отвечает на старую переписку;
- обращается только по имени Telegram; фамилию не использует;
- если имени нет, пишет просто «Здравствуйте!»;
- не возобновляет диалог без нового входящего сообщения;
- не называет ИИ-помощников ботами;
- при запросе встречи обязательно выясняет дату/время, часовой пояс и формат: Zoom, Telegram или WhatsApp;
- МСК используется как основной стандарт, местное время человека рассчитывается отдельно;
- перед подтверждением реально проверяет таблицу `agency_meetings`;
- перед финальной записью повторно проверяет занятость;
- фразу «встреча внесена в календарь» отправляет только после успешного INSERT в Supabase;
- если время занято, ищет ближайшие свободные варианты.

## Важное ограничение этапа 1

В интерфейсе Streamlit входящие проверяются вручную кнопкой «Проверить входящие сейчас». Это сделано специально для безопасного тестирования.

Файл `neona_worker.py` уже подготовлен для следующего этапа — круглосуточной работы на отдельном серверном worker. Один только Streamlit Community Cloud не является надёжным 24/7 Telegram-worker: приложение может перезапускаться или засыпать при отсутствии активности.

## Установка

1. Supabase -> SQL Editor: выполнить `neona_dialog_states.sql` один раз.
2. В GitHub заменить `streamlit_app.py`.
3. Добавить `neona_telegram_dialogs.py`.
4. Добавить `neona_worker.py` и `requirements_worker.txt` — они пока лежат как заготовка для следующего этапа.
5. `assets`, `README.md`, `neona_reglament.py`, `agency_calendar.py` не менять.

## Первый безопасный тест

1. Открыть Агентство W -> Агенты -> Неона.
2. Раскрыть «Входящие сообщения Telegram — тест».
3. Один раз нажать «Проверить входящие сейчас». На этом шаге Неона только создаст точку отсчёта и никому не ответит.
4. Попросить человека, которому уже было отправлено первое сообщение из нового Агентства W, написать новое сообщение, например: «Мне нужна встреча завтра в 13:00».
5. Снова нажать «Проверить входящие сейчас».
6. Неона должна поздороваться только по имени и спросить недостающие данные: часовой пояс и формат встречи.
7. После ответа человека снова нажать кнопку. Неона проверит календарь и попросит подтверждение.
8. После «Да» снова нажать кнопку. Только теперь встреча должна появиться в календаре, и только после успешной записи Неона сообщит, что встреча внесена.

После этого можно переходить к развёртыванию `neona_worker.py` как круглосуточного процесса.
