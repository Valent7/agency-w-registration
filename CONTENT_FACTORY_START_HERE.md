# Запуск контент-завода Агентства W

В проект добавлен автопилот для каждого партнёра: свои настройки бренда,
Instagram/Reels, ВК и Threads, календарь, ИИ-генерация, хранение материалов
и очередь публикаций. Отдельные материалы можно создавать прежним способом.

Изменения в этом комплекте ещё нужно установить на работающий сайт.
Публикации с настоящих аккаунтов в ходе разработки не выполнялись.

## Порядок установки

1. В существующем проекте **Supabase** открыть SQL Editor и выполнить
   [content_factory_setup.sql](content_factory_setup.sql). Сначала подготовить
   базу, затем обновлять сайт. Повторное выполнение SQL предусмотрено.
2. Перенести файлы обновления в репозиторий **Valent7/agency-w-registration**.
   Проверить изменения и обновить рабочую версию Streamlit.
3. В **Render** создать два сервиса по файлу
   [deploy/content-factory/render.yaml](deploy/content-factory/render.yaml):
   один подключает Instagram и Threads, второй постоянно обрабатывает очередь.
4. В защищённых настройках Streamlit и Render указать общую базу и одинаковый
   ключ шифрования подключений. Для генерации используется OpenAI. Настроить
   приложения Meta с разрешениями на публикацию и адресами возврата. Все поля
   и команды описаны в [инструкции развёртывания](docs/content_factory_autopilot.md).
   Значения ключей не добавлять в GitHub и не отправлять в чат.
5. В Агентстве открыть **Контент → Автопилот: контент и публикации**,
   создать проект, подключить аккаунты, выбрать время и включить автопилот.

Для первого проекта уже предложены описание Агентства W, аудитория,
русский язык и ссылка https://agency-w.streamlit.app/. Всё можно изменить
для собственного проекта партнёра.

## Как работает автопилот

ИИ создаёт разные материалы по расписанию: текст и иллюстрацию для поста,
3–6 оформленных слайдов для карусели, вертикальное видео с иллюстрацией,
движением кадра, озвучкой и субтитрами. Для площадок создаются собственные
версии с учётом ограничений текста.

При выключенной проверке готовые материалы публикуются автоматически.
При включённой проверке сначала требуется утверждение владельца.
Автопилот можно поставить на паузу, материал — отредактировать до передачи
площадке или отменить. Дневной лимит ограничивает число попыток создания
материалов; он не равен фиксированной денежной стоимости API.

ВК размещает видео на стене сообщества. Нативная публикация в VK Клипы
этим обновлением не заявляется. Instagram и Threads требуют разрешений
соответствующих приложений Meta; одного входа в Агентство недостаточно.

Если связь оборвалась во время публичной отправки, материал получает статус
сверки. Система не отправляет его повторно вслепую.
