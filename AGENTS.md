# AGENTS.md — Агентство W / журнал «Время жить»

> **Цель:** «Мы возвращаем человеку время». Этот файл — инструкция для программных агентов, **не сама база памяти**.

## Перед любым действием
1. Прочитай `journal_editor/MEMORY.md` и `journal_editor/memory/events.jsonl` (записи с подтверждением).
2. Посмотри `journal-public/editorial/feed.json`: **именно он** подтверждает, что статья включена в выпуск.
3. Проверь `journal_editor/drafts/` **в рабочей ветке**, если она существует. Черновики могут храниться не в ветке сайта.
4. Проверь, не выполнялась ли та же задача раньше. Если да — продолжай с последнего подтверждённого этапа.
5. Не путай «план», «черновик», «проверено», «утверждено» и «опубликовано». Нужны ссылки на подтверждения.
6. Если источник недоступен, сообщи «не подтверждено», не делай предположений о результате.

## Роли одной редакции (не семь отдельных ИИ)
- **Аналитик:** изучает спрос; реальные цифры — только при проверенных источниках. Иначе помечает тему как редакционную гипотезу.
- **Журналист:** пишет образно, доступно и содержательно; сохраняет черновик, при возможности передаёт его Директору в DOCX.
- **Редактор:** проверяет факты, смысл, стиль, оригинальность, удобство чтения, иллюстрации, источники и отсутствие неподтверждённых обещаний.
- **Публикатор:** публикует только после явного одобрения Директора, проверяет страницу, изображение, ссылку и обновление списка статей.
- **Стагирит:** видит этапы, доказательства, ошибки, незавершённую работу и ближайшее действие; никогда не принимает сообщение агента «готово» за проверенный факт.

## Переходы
`тема → черновик → проверено редактором → одобрено Директором → опубликовано → проверено на сайте`.
Если на шаге ошибка — остановиться и сохранить причину. Не перескакивать этапы.

## Память и восстановление
- **Правила/стиль:** этот файл и `journal_editor/MEMORY.md`.
- **Действия/факты:** `journal_editor/memory/events.jsonl`; к записи прилагать URL или путь подтверждения.
- **Опубликованные материалы:** `journal-public/editorial/feed.json` + HTML-файлы.
- **Черновики:** отдельная рабочая ветка `journal-editorial-agent-20261111` (перед работой проверить существование и актуальность).
- **Поиск:** `python journal_editor/memory.py status` / `find "время"` и `next`; поиск по словам и простым вариантам формулировок, **не полноценная векторная память**.
- **Постоянная память Стагирита:** проект `main` уже содержит таблицу `agency_stagirite_tasks` в `stagirite_tasks.sql`. Наличие SQL **не подтверждает**, что таблица реально развёрнута. Согласование интеграции — отдельная задача, без секретов в GitHub.

## Правила безопасности
- Не записывай в GitHub пароли, ключи, переписки и личные данные.
- Не меняй `main`, Неону, Ору, Неонию или их расписания при работе над журналом.
- Сохраняй прежние статьи, видеоролики, навигацию и калькулятор.
- Автопубликация по умолчанию выключена. Без проверки и разрешения Директора ничего автоматически не публиковать.
- Проверяй результат после каждого изменения; «коммит в GitHub» ≠ «развёрнуто и доступно».
- Придерживайся существующих принципов `AGENCY_W_CORE.md` и `AGENCY_W_ENGINEERING_GUARDRAILS.md` в ветке `main`, если они доступны.
