NEONA 3.0 — «ЛЕГКО, ИНТЕРЕСНО, ПРИЯТНО»
Дата: 04.10.2026

ЗАЧЕМ ЭТО ОБНОВЛЕНИЕ
--------------------
V2 хорошо держит жёсткие границы и календарь.
V3 добавляет то, чего не хватало: единый характер и смысловое ведение разговора.

Неона 3.0:
- сначала понимает смысл последней реплики в контексте;
- не отвечает по одному ключевому слову;
- допускает лёгкий юмор, метафоры, редкую уместную латынь;
- подстраивается под человека;
- помнит деловую цель Агентства W;
- не показывает календарь без согласия на встречу;
- сохраняет все сегодняшние V2-защиты.

МОДЕЛЬ
------
Свободный смысловой диалог V3 по умолчанию использует gpt-6.1-sol.
Если эта модель недоступна аккаунту, код автоматически пробует gpt-6-luna,
а затем gpt-5-mini.

Новые Secrets не обязательны.

При желании модель можно изменить через:
NEONA_DIALOG_MODEL
NEONA_DIALOG_FALLBACK_MODEL

ПЕРВЫЕ ЖИВЫЕ ТЕСТЫ
------------------
1. Человек шутит: «Я с роботом общаюсь 😂»
   Ожидание: честный, лёгкий ответ; никакой обиды и никакого врача.

2. Человек рассказывает о семье/путешествиях.
   Ожидание: поддержать именно сказанное, не выдумывать медицинскую тему.

3. Человек говорит, что у него уже есть ИИ.
   Ожидание: не спорить; посмотреть, решена ли задача поиска людей у команды.

4. Человек заинтересовался Агентством.
   Ожидание: спросить, хочет ли он поговорить с Валентиной.
   НЕ показывать время.

5. Только после «Да, хочу поговорить с Валентиной».
   Ожидание: 2–3 свободных времени по МСК.

6. Явный отказ.
   Ожидание: спокойно завершить без дожима.
