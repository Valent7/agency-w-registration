# Карточка человека 2.0 — этап 1

Это безопасная read-only версия единой карточки человека.

## Что меняется

- добавляется новый модуль `person_card.py`;
- в рабочей карточке выбранного человека у Неоны появляется раскрываемый блок `🧭 Карточка человека 2.0`;
- карточка объединяет уже существующие данные Неонии, первого сообщения и состояния диалога Неоны;
- показывает тип контакта, текущий этап, последнее значимое событие, следующий допустимый шаг, основания рекомендации, известные сведения, границы общения и краткую историю ключевых событий.

## Что НЕ меняется

- логика Неонии;
- генерация первых сообщений Неоны;
- обработка входящих и возражений;
- календарь;
- Стагирит;
- Неола;
- структура Supabase.

Новый SQL выполнять не нужно.

## Файлы для GitHub

Загрузить в корень репозитория:

1. `streamlit_app.py` — заменить существующий;
2. `person_card.py` — новый файл;
3. `PERSON_CARD_2_0_SETUP.md` — документ установки.

## Проверка после Commit

1. Открыть Агентство W.
2. `Агенты → Неона`.
3. Открыть любого выбранного человека.
4. Убедиться, что появился блок `🧭 Карточка человека 2.0`.
5. Раскрыть его и проверить текущий этап и следующий допустимый шаг.

Первая версия только читает данные и ничего сама не отправляет и не изменяет.
