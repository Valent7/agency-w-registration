# Неона — база возражений 1.0

## Что добавлено

- Неона различает **мягкое возражение** и **явную просьбу прекратить контакт**.
- «Нет времени», «мне это не нужно», «у меня уже есть ИИ», «дорого» и похожие сомнения больше не завершают разговор автоматически.
- Мягкое возражение Неона может содержательно отработать **один раз**: услышать → один проверенный факт → один маленький вопрос.
- Если человек повторяет то же сомнение без нового интереса, Неона уважительно завершает разговор.
- «Не пишите», «не присылайте», «больше не беспокойте», «удалите мой контакт» и похожие формулировки — немедленный стоп без нового аргумента.
- Если точного факта нет, Неона не выдумывает ответ и передаёт вопрос Директору.
- Для конкурентов действует правило: признать подтверждённую сильную сторону, не очернять, использовать только проверенный факт и только одно релевантное отличие W.
- В первую мини-базу внесены подтверждённые карточки Sintra AI и Artisan Ava; O-Key AI и myaibox.ai помечены как требующие отдельной проверки, чтобы Неона не фантазировала.

## Проверка после Commit

После перезапуска Streamlit проверить последовательно:

1. «У меня нет времени на просмотры» → Неона не прощается, а один раз отвечает по смыслу и задаёт максимум один вопрос.
2. Повтор «Нет, мне всё равно не нужно» того же типа → Неона перестаёт уговаривать и уважительно завершает.
3. «У меня уже есть Sintra» → Неона признаёт конкурентный сервис, не говорит «мы лучше», использует максимум один подтверждённый факт/отличие.
4. «Не надо мне присылать, пожалуйста» → Неона подтверждает границу и больше не аргументирует.
5. После молчания Неона сама не пишет повторно — прежнее правило сохраняется.
