# agency-w-registration

Публичная регистрация и личный кабинет Агентства W.

Фирменная шапка собрана правильно:
- изображение содержит только прозрачную эмблему W;
- золотая волна хранится отдельным прозрачным файлом;
- надписи «Агентство W», «Acta, non verba.», «Дела, а не слова.» и «Мы создаём своё настоящее» выводятся настоящим текстом сайта;
- на странице регистрации используется крупная версия шапки;
- в личном кабинете — компактная версия;
- во вкладке браузера отображается только эмблема W.
