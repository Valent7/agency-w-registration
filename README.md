# agency-w-registration

Публичная регистрация и личный кабинет Агентства W.

Фирменный стиль:
- золотой логотип на чёрном фоне;
- девиз «Acta, non verba.» / «Дела, а не слова.»;
- основной смысл: «Мы создаём своё настоящее»;
- логотип используется на странице регистрации, в личном кабинете и как значок браузера.
