# Агентство W — исправление логотипа и черновиков Неоны

В этой версии:

- исправлен `assets/agency_w_icon.png`: в изображении осталась только эмблема W, без случайных букв и текста;
- регистрационная и главная страницы используют исправленную эмблему;
- старые сообщения Неоны, сохранённые до нового регламента, автоматически снимаются с утверждения;
- добавлены кнопки «Сформировать все сообщения заново» и «Удалить все черновики»;
- у каждого кандидата добавлены кнопки «Заново» и «Удалить»;
- новое сообщение создаётся по действующему правдивому регламенту;
- утвердить сообщение, нарушающее регламент, нельзя;
- обновлён безопасный текст первого сообщения: Агентство W описывается как команда ИИ-помощников, которая уже умеет искать подходящих людей и помогать начать личный разговор.

После загрузки файлов в GitHub дождитесь перезапуска Streamlit и выполните жёсткое обновление страницы: `Command + Shift + R`.
