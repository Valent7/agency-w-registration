# agency-w-registration

Публичная регистрация и личный кабинет «Агентства W».

## Подключено в этой версии

- регистрация и вход через Telegram;
- сохранение рабочего состояния в Supabase;
- поиск Telegram-контактов;
- поиск доступных Telegram-групп, супергрупп и каналов;
- фильтр чатов по названию, username и типу;
- отдельное отображение архивных чатов;
- выбор группы для поиска людей по критериям ЦА;
- загрузка доступных участников выбранной группы;
- анализ участников партиями по 10 на основании паспорта ЦА, bio и публичных сообщений в выбранном чате;
- счётчики анализа и таблица 10 лучших кандидатов;
- добавление подходящих участников в общий пул Неонии;
- фирменная шапка и значок Агентства W.

## Важные ограничения

- каналы не используются для поиска участников;
- Telegram может скрывать или ограничивать список участников некоторых групп;
- личная переписка и номера телефонов участников чата не анализируются;
- Неония рекомендует кандидатов, но решение принимает владелец кабинета;
- автоматическая массовая рассылка не выполняется.
