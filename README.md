# agency-w-registration

Публичная регистрация и личный кабинет Агентства W.

Фирменное оформление:
- прозрачный золотой логотип накладывается непосредственно на фон сайта;
- логотип отображается на странице регистрации и в личном кабинете;
- браузер использует отдельную прозрачную иконку W;
- девизы: «Acta, non verba.» / «Дела, а не слова.»;
- основной смысл: «Мы создаём своё настоящее».
