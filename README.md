# Агентство W — команда ИИ-помощников и правила Неоны

В этой версии:

- Неона никогда не называет ИИ-помощников ботами или чат-ботами;
- Агентство W описывается как растущая команда ИИ-помощников, где каждый отвечает за свою часть работы;
- первое сообщение говорит только о реально работающих функциях: поиске подходящих людей и подготовке персональных первых сообщений;
- количество знаков и предложений больше не используется как причина блокировки;
- сообщение проверяется по смыслу: правда, понятная польза, лёгкая интрига и один вопрос;
- запасной безопасный текст приглашает посмотреть систему на реальном примере;
- будущие возможности не выдаются за уже работающие;
- окончательное решение и отправка первого сообщения остаются за владельцем кабинета.
