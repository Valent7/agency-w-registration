# Агентство W — карточки и выбор кандидатов из чатов

В этой версии после анализа участников выбранного Telegram-чата:

- 10 лучших кандидатов выводятся отдельными карточками;
- владелец может открыть подробную карточку человека;
- в карточке показываются сегмент, процент соответствия, уверенность, основания, bio, доступные публичные сообщения и безопасная тема первого обращения;
- владелец сам выбирает кандидатов галочками;
- действует общий лимит: не более 5 человек, включая знакомых, добавленных вручную;
- выбор сохраняется и передаётся Неоне для следующего этапа;
- эмблема и фирменная шапка не изменялись.
