# Агентство W — формирование первых сообщений Неоной

Обновление добавляет рабочий раздел **Агенты → Неона**.

После того как владелец выбрал до 5 кандидатов и передал их Неоне:

- Неона показывает список выбранных людей;
- формирует отдельное персональное первое сообщение каждому;
- использует паспорт ЦА, карточку кандидата, безопасную тему, bio и публичный контекст чата;
- не сообщает человеку об анализе или рейтинге;
- не обещает доход и не добавляет ссылку в первое сообщение;
- владелец может редактировать текст;
- владелец отдельно утверждает каждое сообщение;
- автоматической отправки на этом этапе нет.
