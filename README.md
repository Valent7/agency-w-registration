# agency-w-registration

Публичная регистрация и вход в Агентство W.

## Фирменный стиль

В проект добавлен единый логотип «Агентство W» с девизом `Acta, non verba.`.
Фраза «ИИ-агентство нового поколения» удалена из логотипа и интерфейса.

Файлы логотипа находятся в папке `assets`:

- `agency_w_logo.png` — горизонтальный логотип для страниц;
- `agency_w_icon.png` — знак для вкладки браузера.
