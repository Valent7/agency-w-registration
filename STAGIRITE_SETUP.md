## Один раз в Supabase

1. Откройте Supabase → SQL Editor.
2. Создайте новый запрос.
3. Вставьте весь текст `stagirite_tasks.sql`.
4. Нажмите Run.

Без SQL Стагирит тоже запустится, но история поручений будет жить только в текущей сессии.

## Что умеет Стагирит 1.0

- принимает поручение обычными словами;
- текстовый ввод работает всегда;
- голосовой ввод используется только по желанию и транскрибируется один раз с кэшем;
- простое поручение о встречах маршрутизируется без OpenAI;
- читает календарь и ищет свободный день/окна 10:00–20:00 МСК;
- учитывает часовой буфер между встречами;
- показывает, сколько контактов/кандидатов уже есть у Неонии;
- не выбирает людей вместо владельца;
- контент (посты/анонсы) создаёт одним запросом к OpenAI;
- иллюстрацию не выдумывает: готовит задание будущему визуальному агенту;
- хранит «Мои поручения» в Supabase после запуска SQL;
- позволяет утвердить или отметить поручение выполненным.

## Экономия API

- календарь: 0 запросов OpenAI;
- проверка количества контактов/кандидатов: 0 запросов OpenAI;
- маршрутизация простых поручений: 0 запросов OpenAI;
- посты/анонсы: 1 запрос на поручение;
- голос: 1 транскрибация на новую запись; повтор той же записи берётся из кэша.
