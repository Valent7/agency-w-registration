# Дополнение к маркетинговому ядру v83 для утверждения владельцем

Политика Неонии: делегирование (#126)

Сохранить v83 в истории и включить этот раздел в следующую редакцию ядра владельца пилота. В правилах поиска этот раздел заменяет обязательность сетевого бизнеса и приоритет сегмента по принадлежности к отрасли.

Неония ищет действующих предпринимателей, основателей, региональных руководителей, наставников и лидеров команд. Отрасль может быть любой, включая сетевой бизнес, инфобизнес, инвестиционные и криптовалютные проекты. Основной критерий — публично наблюдаемая работа по поиску партнёров, клиентов или представителей либо по обучению и сопровождению команды. Для отбора нужны проверяемый авторский источник, роль человека и конкретный рабочий процесс. Процесс служит основанием проверить потребность в делегировании. Интерес к услугам, готовность платить или стать партнёром устанавливаются отдельно в диалоге.

Использовать только разрешённую публичную информацию. Проверять активность за 48 часов, исключать повторную выдачу, признаки мошеннических схем, финансовых пирамид и обещаний гарантированной доходности. Интерес к инвестициям или криптовалюте сам по себе не даёт допуска. Исключения профессий сохраняются при отсутствии подтверждённой целевой потребности. Для первой редакции автоматического пилота ИИ/ПО-профили направляются на ручную проверку, даже если виден подходящий рабочий процесс. Неполная пятёрка показывается с фактическим результатом.

Действует только для владельца, утвердившего эту редакцию. История, чужие настройки и действующие диалоги сохраняются. Первое сообщение отправляет владелец.
