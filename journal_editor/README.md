# ИИ-редакция журнала «Время жить» — безопасный пилот

Этот каталог добавляет **редакционный движок**, не заменяя сайт и не затрагивая Неону, Неонию, Ору или основной кабинет Агентства W.

## Что уже предусмотрено

- Отдельный редакционный план `topics.json`. Это **гипотезы редакции**, а НЕ реальные показатели Wordstat: не подменять одно другим.
- Генератор статей с помощью OpenAI Responses API; тексты должны быть понятными читателю и без вымышленных исследований.
- Проверка структуры материала и запрещённых обещаний до записи.
- По умолчанию **только черновики**: `journal_editor/drafts/<slug>.json`.
- Ручное утверждение черновика отдельно от автопубликации.
- Выпуск отдельной SEO-страницы с датой и метаописанием, обновление `journal-public/editorial/feed.json`.
- На главной странице блок новых статей показывается **только после появления опубликованных материалов**, старые статьи и видео остаются без изменений.

## Команды из корня репозитория

```bash
python journal_editor/editor.py --check
OPENAI_API_KEY=... python journal_editor/editor.py --draft
python journal_editor/editor.py --approve kak-ponyat-kuda-uhodit-vremya
# Только после 5 проверенных материалов и отдельного включения:
JOURNAL_AUTOPUBLISH=1 OPENAI_API_KEY=... python journal_editor/editor.py --publish
```

Ключи нельзя вставлять в код, переписку и GitHub-файлы. Для автоматического задания хранить их только в Secrets/Environment Variables.

## Что НЕ сделано

1. Не настроен защищённый планировщик запуска агента. Статический Render-сайт не выполняет Python.
2. Не подключены токены Яндекс Вордстата, Метрики, Вебмастера или Google Search Console; нет оснований утверждать, что темы подобраны по подтверждённому спросу.
3. Нельзя заявлять, что публикации идут автоматически, пока не выполнен реальный контроль полного цикла и не получены ключи.
4. Нет независимого фактчекинга: для тем, где требуются внешние факты, нужен отдельный этап поиска надёжных источников и проверка человеком. До этого использовать только спокойные практические темы без статистики и новостей.

## Безопасное дальнейшее подключение

1. Проверить отображение главной страницы, все старые статьи, видеоролики, ссылки на калькулятор.
2. Получить и проверить пять черновиков с редакторской оценкой; при необходимости исправить промпт и правила.
3. Подключить статистику посещений с учётом конфиденциальности и реальный исследовательский инструмент (Wordstat/Google) только после проверки необходимости.
4. Затем выбрать планировщик без риска для основной ветки `main` (отдельный процесс/репозиторий или Render Cron с учётом цены).
5. Настроить минимальные права доступа только к ветке `agency-w-journal-public`. Каждая публикация — отдельный коммит с защитой от повторов, журналом ошибок и уведомлениями о сбоях.
6. Включить автопубликацию только после полного контрольного прогона.

Отправка новых публикаций читателям, автоматическая обработка контактов и массовая рассылка **не** входят в этот пилот.
