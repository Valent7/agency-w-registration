# Постоянная память редакции — журнал «Время жить»

## Что где хранится

| Данные | Источник истины | Проверка |
|---|---|---|
| Правила и роли | `AGENTS.md` | Читать перед началом работы |
| История редакционных действий | `journal_editor/memory/events.jsonl` | Каждая запись с подтверждением |
| Опубликованные статьи | `journal-public/editorial/feed.json` и HTML | Проверять обе записи |
| Черновики | `journal-editorial-agent-20261111:journal_editor/drafts/*.json` | Смотреть именно указанную рабочую ветку |
| Поручения Стагирита | `main:stagirite_tasks.sql` / `agency_stagirite_tasks` | Проверить, доступна ли реальная база, и права на чтение |

## Важно

`AGENTS.md` сообщает новому агенту **что читать и как действовать**, но сам по себе не сохраняет разговоры, события или смысл. JSONL-файл — первая, проверяемая версия журнала событий. Чтобы изменения сохранялись после завершения работы, его необходимо **фиксировать коммитом Git** в рабочем репозитории. Отдельный файл не синхронизируется автоматически со Стагиритом.

Не переносить в этот открытый репозиторий секреты и частные данные. Для полноценной общей памяти Стагирита потребуется безопасное подключение к уже предусмотренному Supabase/PostgreSQL и раздельные права доступа. Это **ещё не сделано**.

## Жизненный цикл статьи

1. Аналитик `topic_selected`.
2. Журналист `draft_created` — черновик и DOCX для Директора.
3. Редактор `editor_checked` — оценка точности и качества.
4. Директор `owner_approved` — явное согласие на публикацию.
5. Публикатор `published` — файл HTML + запись в feed; без них статус не подтверждается.
6. Стагирит `site_verified` — проверка доступности страницы, изображения и навигации.

Сбои фиксировать отдельным `blocked` и не выдавать результат за завершённую работу.

## Как продолжать после остановки

```bash
python journal_editor/memory.py status
python journal_editor/memory.py find "золотой песок"
python journal_editor/memory.py next
```

Это поиск по тексту и небольшому набору общих русских формулировок, а **не** семантическая модель с векторами.
