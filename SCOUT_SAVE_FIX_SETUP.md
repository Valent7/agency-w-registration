# Разведчик W 1.0 — исправление сохранения истории
Дата: 23.08.2026

## Что исправлено
1. Supabase `SUPABASE_SECRET_KEY` теперь передаётся тем же способом, что и в уже работающих модулях Агентства W: как `apikey`, без `Authorization: Bearer`.
2. При ошибке сохранения интерфейс показывает реальную техническую причину.
3. Добавлена кнопка `💾 Сохранить последний отчёт в историю`, чтобы не запускать веб-разведку повторно только ради сохранения.
4. Разведчик завершает отчёт рекомендацией Директору и не добавляет в финале «Если хотите, могу...». 

## Установка
Заменить в корне GitHub только `scout_center.py` и добавить этот документ при желании.
Повторно выполнять SQL не нужно: таблица `agency_competitor_reports` уже создана.

## Проверка
После перезапуска открыть `Стагирит → Разведчик W`. Если последний отчёт сохранился в `session_state`, нажать `💾 Сохранить последний отчёт в историю`. Если отчёта уже нет после перезапуска, запустить один новый тест и убедиться, что появляется сообщение `Отчёт сохранён в истории Разведчика.` и ниже — `История разведки`.
