# Ора — отдельный тестовый сервис Telegram

Этот код находится в ветке `ora-pilot`; основное Агентство W использует `main` и не затрагивается. Сервис Render имеет собственные переменные окружения и свой URL.

## Render
- Runtime: Python
- Branch: `ora-pilot`
- Build command: `pip install -r ora_pilot/requirements.txt`
- Start command: `cd ora_pilot && uvicorn app:app --host 0.0.0.0 --port $PORT`
- При первом запуске без ключей `/health` покажет, что Telegram и ИИ не подключены. Это ожидаемо.

## Секреты — только через Render Environment
- `TELEGRAM_BOT_TOKEN` — секрет от @BotFather.
- `TELEGRAM_WEBHOOK_SECRET` — длинная случайная строка латинских букв и цифр для проверки вебхука.
- `WEBHOOK_BASE_URL` — публичный URL сервиса Render, без косой черты в конце.
- `TELEGRAM_ALLOWED_CHAT_ID` — числовой ID группы WREMYA после команды /id.
- `OPENAI_API_KEY` — отдельный API-ключ OpenAI, не подписка ChatGPT Plus.
- `OPENAI_MODEL` — необязательно; по умолчанию gpt-4.1-mini.

Не публикуйте ключи в Telegram, GitHub, ChatGPT или скриншотах. Стоимость API зависит от фактического использования; в первую очередь настройте лимиты расхода.


## Несколько Telegram-групп (до 7 и более)
Один бот @OraWremyaBot_bot может быть добавлен в несколько групп. У каждой группы свой Telegram ID.
Первый чат WREMYA уже использует TELEGRAM_ALLOWED_CHAT_ID=-1004303939698 (оставьте как есть).

1. В каждой следующей группе администратор добавляет Ору и отправляет /id@OraWremyaBot_bot. Достаточно получить номер и удалить сообщение.
2. Дополнительные ID внесите одной строкой в Render -> Environment:
   TELEGRAM_ALLOWED_CHAT_IDS=-1001111111111,-1002222222222
   (Это ПРИМЕР. Использовать реальные ID только своих чатов.)
3. Отдельно опишите каждую новую группу, иначе Ора не будет рассуждать на неподходящие темы. Пример переменной:
   TELEGRAM_CHAT_PROFILES_JSON={"-1001111111111":{"name":"Super Jump","topic":"Физические упражнения, обучение и развитие, только проверенные данные"},"-1002222222222":{"name":"Инвестиционные обсуждения","topic":"Финансовая грамотность и управление рисками; никаких обещаний доходности"}}
4. Перезапуск Render применяет изменения. Пока тема новой группы не задана, в ней разрешены только диагностические сообщения и уведомления о необходимости настройки. /ask и /intro не должны отправлять контент WREMYA в другие группы.
5. Автопубликации остаются ОТКЛЮЧЕНЫ. Демонстрационные /preview, /poll и /meeting предназначены только для WREMYA; для иных групп потребуются свои база знаний, календарь и посты.

Внимание: список ID не является списком администраторов и не даёт боту никаких дополнительных Telegram-прав. Каждое сообщество нужно настроить осмысленно и с согласия его владельца.

## Как начать
1. Добавьте @OraWremyaBot_bot в группу WREMYA (уже сделано).
2. В Render сохраните TELEGRAM_BOT_TOKEN, TELEGRAM_WEBHOOK_SECRET и WEBHOOK_BASE_URL (секреты заполняет сам владелец).
3. Перезапустите сервис, чтобы он зарегистрировал защищённый webhook.
4. Администратор пишет /id в группе, чтобы получить ID. При необходимости дайте боту минимальные права, чтобы Telegram позволил проверить администратора.
5. В Render добавьте TELEGRAM_ALLOWED_CHAT_ID, дождитесь перезапуска.
6. В группе администратор проверяет /status, /intro, /preview science, /preview thought, /preview humor, /meeting wednesday, /poll. Все действия реальные, но только по команде.
7. После добавления OPENAI_API_KEY любой участник группы может спросить через /ask вопрос.

**Автоматические сообщения, автономная модерация, публикация по календарю, реальная проверка источников, генерация картинок, база знаний и память ещё НЕ реализованы.** Даже после деплоя не обещайте их как существующие. 

**Безопасность:** пока ID группы не задан, бот игнорирует все команды кроме /id администратора. В неразрешённых группах после привязки также не работает. Telegram Privacy Mode можно оставить включённым на первом этапе.

**Остановить** работу можно отключением сервиса или удалением/отзывом Telegram-токена в BotFather.
